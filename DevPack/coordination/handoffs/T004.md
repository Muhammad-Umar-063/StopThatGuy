**Behavior implemented**
- `npm run check` is the single required command: typecheck → build → test → validate → smoke. CI runs the same command.
- `scripts/smoke.ts` (`npm run smoke`) checks the built server's `/health` versions. It then loads the Vite preview of the built client in headless Chrome over the DevTools protocol and checks that the renderer starts, frames advance, the label shows "protocol v1", and there are no console errors, exceptions or failed resources. It uses free ports and bounded timeouts, and stops only its own process groups. A missing browser or build fails the check. It needs no new dependency.
- `validateWorldData` (test-support): a strict structural check, then identity, reference and topology checks, reported with shared `WorldIssueCode`s (`duplicateId` was added to them). There are 22 `INVALID_WORLD_SAMPLES`, each required to produce exactly its intended code. `checkWorldConsistency` now delegates to it.
- Asset manifest schema 1 and its validator (`@stopthatguy/test-support/node`). `assets/manifest.json` is explicitly `empty-development`.
- `scripts/validate-data.ts` (`npm run validate`) runs the world and manifest checks and states what remains unverified.
- `createFixtureUiAdapter` and `createFixtureSimulationSetup`, plus root `tests/` covering fixtures with the real simulation, browser-safe sources and test-support not being a production dependency.
- `.github/workflows/ci.yml` at the repository root: `npm ci` and `npm run check` in `DevPack`, with npm cache keyed on `DevPack/package-lock.json` and smoke artifacts uploaded.
