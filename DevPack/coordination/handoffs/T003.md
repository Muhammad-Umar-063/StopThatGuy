- **Status:** done. Integrated on `main` at `50d552d`; a clean `npm ci` and `npm run check` were re-run on the committed tree (exit 0).
- **Behavior:** `@stopthatguy/simulation` provides `createSimulation({ movement? })`, which implements `Simulation<SimulationState>`:
  - Initial state is built from world, tuning, seed, mode and participants; the seed picks the robber escape route.
  - `step` advances exactly one tick in a single ordered pipeline (phase clock → inputs → movement → reserved slots → escape/timeout).
  - Edge actions apply once each, and acknowledgements are tracked.
  - The countdown → intro → chase phases fire on schedule, the time limit ends the match as a no-winner timeout, and events are numbered and drained as copies.
  - Every future action is reported as unavailable.
  - It also provides the sfc32 RNG, the caller-owned fixed-step accumulator with bounded catch-up, and the pure `MovementKernel` interface with `poseOnRoute` and `indexWorld` (`./movement` subpath).
- **Files:** `packages/simulation/**` (new), `packages/shared/src/simulation.ts` (`roomCode`, `sequence`, documented semantics), doc comments in `ids.ts`/`entities.ts`, the results-phase rule in `packages/test-support/src/fixtures/consistency.ts`, root `package.json`/lockfile (build order, check order), CONTRACTS/ARCHITECTURE/DECISIONS/README/CHANGELOG.
- **Checks:** `npm run check` (typecheck → build → test) exits 0. Simulation tests pass 30/30 and the T002 tests 97/97. The simulation tests cover:

  - Seeded route choice: both routes occur across seeds, and each seed is stable.
  - RNG output against an independent Python reference.
  - Tick and phase schedule; invalid deltas and inputs throw with no change; exactly-once actions; neutral input for omitted players.
  - Events drain once; snapshot and event mutation has no effect; frozen and cloned setups are untouched.
  - Source contains no forbidden imports or globals; the compiled `dist` resolves under plain Node and matches the source build.
- **Runtime checks:** `dev:server` and `start:server` return versioned `/health`. `dev:client` and `preview:client` render in headless Chrome 154 (SwiftShader) with no console errors.

Determinism is shown only within one runtime (Node 24 / V8). No per-tick performance figures have been measured.
